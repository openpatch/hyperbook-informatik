# Klassifikator

Ein Klassifikator ist ein :t[diskriminatives]{#diskriminative-ki} Verfahren, das einen Datenpunkt einer von mehreren Klassen zuordnet.

Er wird mit gelabelten :t[Trainingsdaten]{#trainingsdaten} trainiert und an ungesehenen :t[Testdaten]{#testdaten} gemessen. Ein einfacher Klassifikator ist :t[k-NN]{#k-nn}.
