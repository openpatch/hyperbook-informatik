# Backpropagation

Backpropagation ist das Verfahren, mit dem ein :t[neuronales Netz]{#neuronales-netz} lernt. Der Fehler wird von der Ausgabeschicht rückwärts durch das Netz gereicht; für jedes Gewicht wird bestimmt, wie stark es zum Fehler beigetragen hat, und es wird ein kleines Stück in die Gegenrichtung korrigiert.

Wie groß dieser Schritt ist, steuert die :t[Lernrate]{#lernrate}.

Der Vorwärtsdurchlauf davor heißt :t[Forward Propagation]{#forward-propagation}.
