# HTML

**HTML** (HyperText Markup Language) ist eine **Auszeichnungssprache**. Sie sagt nicht, wie etwas aussieht, sondern **was** es bedeutet: Das hier ist eine Überschrift, das ein Absatz, das eine Liste.

Ein HTML-Element besteht aus Starttag, Inhalt und Endtag; im Starttag können Attribute stehen:

```html
<a href="seite.html">Zur nächsten Seite</a>
```

HTML ist keine Programmiersprache – man rechnet damit nichts aus. Für das Aussehen ist :t[CSS]{#css} zuständig.
