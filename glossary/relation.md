# Relation

Eine **Relation** ist der Fachbegriff für eine Tabelle einer relationalen Datenbank. Sie ist eine Menge gleichartiger :t[Tupel]{#tupel}.

Zwei Regeln machen aus einer Tabelle eine Relation: Jeder :t[Attributwert]{#attribut} ist atomar – in einer Zelle steht genau ein Wert –, und die Reihenfolge der Zeilen hat keine Bedeutung. Aus der zweiten Regel folgt, dass man eine Zeile nicht über ihre Position ansprechen kann, sondern nur über ihre Werte.

Wie eine Relation aufgebaut ist, beschreibt ihr :t[Relationenschema]{#relationenschema}.
