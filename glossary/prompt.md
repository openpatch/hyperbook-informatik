# Prompt

Ein Prompt ist die Eingabe an ein :t[generatives]{#generative-ki} KI-System.

Das bewusste Formulieren solcher Eingaben heißt **Prompt Engineering**. Ein guter Prompt enthält eine klare Anweisung, Kontext (für wen, wie lang, welcher Stil), bei Bedarf Beispiele und oft eine Rollenzuweisung.

Faustregel: Je mehr Entscheidungen der Prompt schon trifft, desto weniger trifft sie das Modell nach eigenem Ermessen.
