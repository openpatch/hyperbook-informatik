# Binärsystem

Das Binärsystem (auch Dualsystem) ist ein Stellenwertsystem mit nur zwei Ziffern, 0 und 1. Jede Stelle ist doppelt so viel wert wie die Stelle rechts von ihr: 1, 2, 4, 8, 16, … Beispiel: 1011₍₂₎ = 8 + 2 + 1 = 11₍₁₀₎. Computer verwenden das Binärsystem, weil sich zwei Zustände (Strom an oder aus) technisch sicher unterscheiden lassen.
