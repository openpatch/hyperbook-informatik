# Fremdschlüssel

Ein **Fremdschlüssel** ist ein Attribut (oder eine Attributmenge) einer :t[Relation]{#relation}, das auf den :t[Primärschlüssel]{#primaerschluessel} einer anderen Relation verweist. So werden Tabellen miteinander verbunden.

Das Datenbanksystem wacht darüber, dass jeder Fremdschlüsselwert in der Zieltabelle auch wirklich vorkommt. Diese Bedingung heißt **referenzielle Integrität**.
