# Unteranpassung

Unteranpassung (Underfitting) heißt: Ein Modell ist zu einfach, um die Muster in den Daten überhaupt zu erfassen.

Man erkennt sie daran, dass **beide** Quoten schlecht sind — auf den :t[Trainingsdaten]{#trainingsdaten} wie auf den :t[Testdaten]{#testdaten}. Bei :t[k-NN]{#k-nn} tritt sie auf, wenn k so groß gewählt wird, dass immer die Gesamtmehrheit gewinnt.

Das Gegenstück ist die :t[Überanpassung]{#ueberanpassung}.
