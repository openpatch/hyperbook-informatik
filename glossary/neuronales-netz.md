# Neuronales Netz

Ein künstliches neuronales Netz besteht aus :t[Neuronen]{#neuron}, die in Schichten angeordnet sind:

- **Eingabeschicht:** nimmt die Rohdaten auf, ein Neuron je Merkmal.
- **Verdeckte Schichten:** liegen dazwischen und verarbeiten; von außen nicht sichtbar.
- **Ausgabeschicht:** liefert das Ergebnis.

Der Vorwärtsdurchlauf heißt :t[Forward Propagation]{#forward-propagation}, das Lernen :t[Backpropagation]{#backpropagation}.
