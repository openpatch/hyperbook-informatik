# URL

Eine **URL** ist die Adresse einer Ressource im Web. Sie hat feste Bestandteile:

```
https://example.org/pfad/datei.html?suche=css#kapitel2
```

| Teil | Bedeutung |
| --- | --- |
| `https` | Protokoll |
| `example.org` | Servername, wird über das DNS in eine IP-Adresse übersetzt |
| `/pfad/datei.html` | Pfad auf dem Server |
| `?suche=css` | Abfrage |
| `#kapitel2` | Sprungziel **innerhalb** der Seite – wird nicht an den Server geschickt |
