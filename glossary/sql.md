# SQL

**SQL** (Structured Query Language) ist die Standardsprache für relationale Datenbanken. Sie ist **deskriptiv**: Man beschreibt, welche Daten man haben will, nicht wie der Rechner sie findet.

SQL besteht aus mehreren Teilen:

- **Datenabfragesprache** – `SELECT`
- **Datendefinitionssprache** – `CREATE`, `ALTER`, `DROP`
- **Datenmanipulationssprache** – `INSERT`, `UPDATE`, `DELETE`

Das Ergebnis einer Abfrage ist immer wieder eine Tabelle.
