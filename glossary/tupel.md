# Tupel

Ein **Tupel** ist eine einzelne Zeile einer :t[Relation]{#relation}, also ein Datensatz. Es beschreibt genau ein Objekt der realen Welt – eine Bühne, eine Person, einen Auftritt.

Eindeutig ansprechbar wird ein Tupel durch den :t[Primärschlüssel]{#primaerschluessel} seiner Relation.
