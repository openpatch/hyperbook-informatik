# Maschinelles Lernen

Maschinelles Lernen (ML) ist der Teil der :t[künstlichen Intelligenz]{#kuenstliche-intelligenz}, bei dem ein Verfahren seine Regeln nicht vorgegeben bekommt, sondern sie aus Daten ableitet.

Man unterscheidet drei Arten danach, was dem System beim Lernen zur Verfügung steht:

- **Überwachtes Lernen:** Zu jedem Trainingsdatensatz gibt es ein :t[Label]{#label} mit der richtigen Antwort. Beispiel: :t[k-NN]{#k-nn}.
- **Unüberwachtes Lernen:** Es gibt keine Labels, das System sucht selbst nach Gruppen und Mustern. Beispiel: :t[k-Means]{#k-means}.
- **Bestärkendes Lernen:** Es gibt weder Labels noch Vorgaben, sondern Belohnung und Bestrafung. Beispiel: eine Spiel-KI.

Eine vierte Bezeichnung trifft man bei Sprachmodellen: Beim **selbstüberwachten** Lernen erzeugt das System seine Zielwerte selbst aus den Daten — jedes Wort eines Textes ist das Lernziel für das vorhergehende.
