# Präzision

Die Präzision beantwortet die Frage: Von allen Fällen, die ein Modell als „positiv" eingestuft hat — wie viele waren es wirklich?

Präzision = TP / (TP + FP)

Eine hohe Präzision bedeutet wenige Falsch-Positive. Sie ist besonders aussagekräftig, wenn die positive Klasse selten ist: Dort sieht die reine Trefferquote gut aus, obwohl das Modell kaum etwas leistet.
