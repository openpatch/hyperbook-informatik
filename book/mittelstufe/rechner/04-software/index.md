# Von der Hardware zur Software

## Worum geht es hier?

Ein Addierwerk allein macht noch keinen Computer, auf dem du ein Spiel startest oder eine Nachricht schreibst. In diesem Kapitel siehst du, wie Hardware und Software zusammenarbeiten – vom Bitmuster im Prozessor bis zur App auf dem Bildschirm. Am Ende nutzt du dein Wissen, um eine echte Kaufentscheidung zu treffen.

## Für dieses Kapitel musst du …

- die Bauteile eines Computers kennen ([Kapitel 1](../01-aufbau))
- Binärzahlen lesen können ([Kapitel 2](../02-binaersystem))
- wissen, was ein Addierwerk tut ([Kapitel 3](../03-schaltungen/03-addierer))

## Hier lernst du …

- wie Hardware, Betriebssystem und Anwendungen **aufeinander aufbauen**
- wie ein Prozessor ein Programm **Befehl für Befehl** ausführt
- welche Arten von Software und welche **Lizenzen** es gibt
- einen Computer nach **Anforderungen** auszuwählen und eine Kaufentscheidung zu **begründen**
