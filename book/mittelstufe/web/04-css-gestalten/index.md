# CSS: gestalten

## Worum geht es hier?

:t[HTML]{#html} sagt, **was** etwas ist. :t[CSS]{#css} sagt, **wie** es aussieht. Diese Trennung ist der Grund, warum dieselbe Seite auf dem Handy anders aussehen kann als auf dem Bildschirm – ohne dass man den Inhalt zweimal schreiben muss.

## Für dieses Kapitel musst du …

- HTML-Elemente auszeichnen können ([Kapitel 2](../02-html-inhalte-auszeichnen))
- den Baum hinter einer Seite verstehen ([Kapitel 3](../03-quelltexte-analysieren/01-der-baum-hinter-der-seite))

## Hier lernst du …

- wie CSS mit einer Seite verbunden wird
- Elemente gezielt ansprechen und verstehen, welche Regel gewinnt
- Farben, Schriften und wiederverwendbare Werte
- das Boxmodell: Rand, Rahmen, Innenabstand
- Elemente nebeneinander anordnen mit Flexbox und Grid
- eine Seite, die auf jedem Bildschirm funktioniert
