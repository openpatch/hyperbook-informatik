# HTML: Inhalte auszeichnen

## Worum geht es hier?

:t[HTML]{#html} ist keine Programmiersprache. Man rechnet damit nichts aus und trifft keine Entscheidungen. HTML ist eine **Auszeichnungssprache**: Du nimmst einen Text und sagst dazu, **was** die einzelnen Teile bedeuten – das hier ist eine Überschrift, das ein Absatz, das eine Liste.

Wie es aussieht, entscheidet später :t[CSS]{#css}. Das klingt nach einer Kleinigkeit, ist aber der wichtigste Gedanke des ganzen Kapitels.

## Für dieses Kapitel musst du …

- wissen, was beim Aufruf einer Seite passiert ([Kapitel 1](../01-wie-das-web-funktioniert/01-vom-klick-zur-seite))

## Hier lernst du …

- das Grundgerüst jeder HTML-Datei
- Texte auszeichnen: Überschriften, Absätze, Betonungen
- Listen und Tabellen aufbauen
- Links setzen und Bilder einbinden – auch für Menschen, die nicht sehen können
- eine Seite in sinnvolle Bereiche gliedern
