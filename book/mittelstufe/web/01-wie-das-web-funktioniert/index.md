# Wie das Web funktioniert

## Worum geht es hier?

Bevor du eine eigene Webseite baust, solltest du wissen, was beim Aufrufen einer Seite eigentlich passiert – und wie man einer fremden Seite unter die Haube schaut.

## Hier lernst du …

- was zwischen deinem Gerät und einem Webserver hin- und hergeschickt wird
- wozu eine Adresse wie `https://informatik.openpatch.org/mittelstufe/web` die einzelnen Teile hat
- wie du mit den Entwicklerwerkzeugen deines Browsers den Quelltext und die übertragenen Daten einer Seite untersuchst
- warum Zeichen in einer Datei codiert werden müssen und was dabei schiefgehen kann
