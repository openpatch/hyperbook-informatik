# Quelltexte analysieren

## Worum geht es hier?

Selbst schreiben ist das eine. Einen **fremden** Quelltext lesen und beurteilen ist das andere – und im Alltag häufiger. Jedes Mal, wenn du eine Seite untersuchst, tust du genau das.

## Für dieses Kapitel musst du …

- die :t[HTML]{#html}-Elemente aus [Kapitel 2](../02-html-inhalte-auszeichnen) kennen

## Hier lernst du …

- einen Quelltext als Baum lesen und daraus die Verschachtelung ablesen
- Fehler in fremdem HTML finden, obwohl der Browser keine Fehlermeldung zeigt
- beurteilen, ob ein Quelltext gut ausgezeichnet ist
