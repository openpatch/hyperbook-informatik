# Bibliotheken

## Worum geht es hier?

Vieles, was man häufig braucht, hat schon jemand geschrieben. Eine **Bibliothek** einzubinden heißt, fremden Code zu benutzen – eine der wichtigsten Fertigkeiten überhaupt, und eine, die weit über OpenSCAD hinausreicht.

## Für dieses Kapitel musst du …

- eigene Module schreiben können ([Kapitel 4](../04-parameter-und-wiederholung))

## Hier lernst du …

- wie du eine Bibliothek einbindest und ihre Dokumentation liest
- wie du abgerundete Formen erzeugst, ohne sie selbst zu konstruieren
- wie **Anker** das mühsame Ausrechnen von Positionen ersetzen
- wie `diff()` Löcher übersichtlicher macht als `difference()`
- wie aus mehreren Profilen ein durchgehender Körper entsteht
