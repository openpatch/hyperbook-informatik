# Programmierung mit Java

Hier findest du zwei aufeinander aufbauende Lernpfade, mit denen du das Programmieren in **Java** von Grund auf lernst.

Programmiert wird direkt im Browser – du musst nichts installieren. Wenn eine Zeichnung, eine Animation oder ein Spiel entstehen soll, nutzen wir die Bibliothek **Scratch for Java**.

## Die beiden Lernpfade

1. **[Grundlagen der Programmierung mit Java](./01-grundlagen)** – Einführungsphase
   Von der ersten Ausgabe über Variablen, Kontrollstrukturen und Methoden bis zur Objektorientierung und zu ersten Such- und Sortierverfahren.

2. **[Erweiterungen der Programmierung mit Java](./02-erweiterungen)** – Qualifikationsphase
   Polymorphie und abstrakte Klassen, Rekursion, dynamische Datenstrukturen, effiziente Such- und Sortierverfahren, Laufzeitbetrachtungen.

Modellierungsdiagramme zum Nachschlagen findest du unter [Objektorientierte Modellierung](../oom).
