# Abfragen mit SQL

## Worum geht es hier?

SQL ist eine **deskriptive** Sprache: Du beschreibst, welche Daten du haben willst, nicht wie der Rechner sie findet. Das ist ungewohnt, wenn man Java gewohnt ist – und macht viele Aufgaben erstaunlich kurz.

## Für dieses Kapitel musst du …

- den Aufbau einer relationalen Datenbank kennen ([Kapitel 1](../01-daten-in-tabellen/02-aufbau-einer-relationalen-datenbank))
- das Schema der Festivaldatenbank zur Hand haben ([Kapitel 1](../01-daten-in-tabellen/03-die-festivaldatenbank))

## Hier lernst du …

- Spalten auswählen und benennen
- Zeilen filtern – mit Vergleichen, Verknüpfungen, Mustern, Mengen und Bereichen
- Ergebnisse sortieren, Doppelte entfernen und die Ausgabe begrenzen
- in einer Abfrage rechnen
